How to get your data

Android

  1. Settings → Location → Location services → Timeline
  2. Export Timeline data → Timeline.json

iPhone

  1. Google Maps → profile picture → Your Timeline
  2. ⋯ → Location & privacy settings → Export Timeline data

Immich photos

  1. Self-hosted: ⚙ Settings → Immich, photos load automatically
  2. Opened as a file: node immich-export.mjs, then drop immich-photos.json

Old Google Takeout

  1. Drop Records.json or the whole Semantic Location History folder

      OwnTracks is a free, open-source app for iPhone and Android that sends your location here in the background, so new trips appear without exports.

      Set OWNTRACKS_AUTH=user:password (or BASIC_AUTH) on the server to turn this on.
