How to get your data

Android

  1. Settings → Location → Location services → Timeline
  2. Export Timeline data → Timeline.json

iPhone

  1. Google Maps → profile picture → Your Timeline
  2. ⋯ → Location & privacy settings → Export Timeline data

Immich photos

  1. Immich → Account Settings → API Keys
  2. IMMICH_URL=… IMMICH_API_KEY=… node immich-export.mjs
